# News in English by Levels

A React app for reading English news at three difficulty levels.

## Demo

[Open the live app](https://ytre12.github.io/NewsOnEnglich/)

## Features

- Read news at Levels 1, 2, and 3
- Filter articles published today
- Browse articles with pagination
- Save favorite articles in the browser

## Built with

- React
- Vite
- Tailwind CSS
- Node.js and Cheerio for scraping news data
- GitHub Actions for deployment and data updates

## Run locally

Requirements: Node.js 20 or newer.

```bash
git clone https://github.com/ytre12/NewsOnEnglich.git
cd NewsOnEnglich
npm ci
npm run dev
